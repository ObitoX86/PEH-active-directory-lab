# Evidence Standards

Screenshots and outputs should correspond to actions actually performed in the user's authorised virtual lab.

## File naming

`YYYY-MM-DD_phase_topic_step.png` or `YYYY-MM-DD_phase_topic_output.txt`

## Redaction checklist

- Remove passwords, hashes, tickets, private keys and session tokens.
- Remove personal details and real organisation identifiers.
- Avoid publishing unnecessarily identifiable hostnames or internal addresses.
- Capture enough interface or terminal context to show the actual observation.
- Never fabricate or alter technical outcomes; redact only sensitive information.
